# DocuMind

Production Agentic RAG Platform built with:

- FastAPI
- FAISS
- PostgreSQL
- Sentence Transformers
- Cross-Encoder Reranking
- Docker
- AWS EC2

## Architecture

Document Ingestion
→ Chunking
→ Embeddings
→ FAISS Retrieval
→ Reranking
→ LLM Generation
→ Citations
